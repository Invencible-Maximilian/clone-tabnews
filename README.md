# Clone-TabNews 🚀

Este repositório é uma implementação experimental e em andamento de uma versão inspirada no TabNews, com foco em frontend e lógica de interface. O objetivo é explorar manipulação de DOM, construção de componentes e organização de código em JavaScript moderno.

🛠 Projeto em desenvolvimento — funcionalidades podem não estar completas.

---

## 📌 Visão Geral

Clone-TabNews é um projeto de estudo que busca replicar funcionalidades e layout inspirados no [TabNews](https://tabnews.com.br). O foco principal está em:

- Construção de interfaces responsivas com HTML, CSS e JavaScript
- Manipulação dinâmica do DOM para interação com usuários
- Organização de componentes front-end
- Boas práticas de estruturação de projeto web
